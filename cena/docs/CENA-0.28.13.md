# CENA IA 0.28.13

- Ao tocar em **Correto**, o CENA guarda até 200 confirmações de títulos completos no aparelho.
- Uma leitura futura equivalente prioriza o filme confirmado entre as opções verificadas no catálogo.
- **Perfil → Memória das capturas** permite apagar as confirmações.
- A edição antes chamada **CENA IA NOVO** agora se chama **CENA IA** e passa a ser a edição oficial. Instale por cima dela para manter os dados. A edição anterior usa outro identificador e foi descontinuada.
