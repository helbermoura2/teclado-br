# CENA IA 0.28.12

- A sinopse aparece no início da ficha, com opção de ler o texto completo.
- Quando o catálogo oferece sinopse em português, o CENA usa essa versão. As demais são traduzidas no celular pelo Google ML Kit.
- O primeiro uso pode precisar de internet para baixar o modelo do idioma. Se a tradução ficar indisponível, a ficha oferece nova tentativa e identifica o texto original.
